# Simulador de Tienda

Simulador de gestión de un entorno comercial diseñado específicamente para implementar conceptos de herencia y manejo de excepciones en Java. 

El núcleo del proyecto es un sistema de jerarquía de clases donde distintos tipos de expositores heredan propiedades comunes pero implementan comportamientos específicos (abrir, cerrar, mostrar stock).

## 🛠️ Tecnologías y Conceptos Aplicados
- **Lenguaje:** Java
- **POO Avanzada:** Herencia, Polimorfismo y Abstracción.
- **Diseño de Software:** Creación de superclases y subclases para modularizar el código y evitar la repetición. Manejo y creación de Excepciones propias y uso de asserts
- **Lógica de Estado:** Gestión interactiva de los estados de los objetos (ej. bloquear acceso si un aparador está cerrado).
